# SSH Фетхие Из Локальной Сети Deco

23 октября2026. Явное разрешение владельца: открыть доступ с локальных
адресов, чтобы смена DHCP IP компьютера не блокировала панель.

## Точный Объём

Добавлено одно правило filter/input local-admin-ssh-deco-v1:
accept,TCP22,src-address192.168.68.0/24,in-interface ether1. Оно стоит
непосредственно перед старым Allow admin Mac from Deco LAN. Старое правило
TCP22/80 с115 не изменено: WebFig80 не расширялся. Никакие иные службы,
публичный SSH или доступ через VPN не открывались. IP/шлюз Mac не менялись.

Любое устройство доверенной сети Deco теперь может пытаться войти по SSH;
аутентификация и закреплённый host key не отменяются. Это осознанно более
широкая локальная граница доверия по запросу владельца, не разрешение Internet.
DHCP reservation Mac115 оставлена пользователем и больше не обязательна
для SSH, пока Mac находится в68/24. За пределами Deco LAN доступ не гарантирован.

## Откат

удалить только filter rule с точным comment local-admin-ssh-deco-v1, сверить
export с before, восстановить прежние baseline_exports.fethiye/baseline.fethiye
из before.json и синхронизировать canonical store. Не восстанавливать весь
router backup и не затрагивать появившиеся позже назначения. Старый доступ
с115 остаётся; сеть Deco и VPN для отката отключать не нужно.
