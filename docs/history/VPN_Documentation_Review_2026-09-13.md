# Ревью VPN-документации: 13 сентября 2026

Пересобраны рабочие архитектурные документы, реестр клиентов, master/runtime-карта, карточки трех VPS, runbooks, указатели и README в System. Проверки документов и сопоставление конфигураций не являются нагрузочным тестом, клиентской проверкой всех устройств или доказательством отсутствия сетевых сбоев.

## Ограничения и следующие отдельные задачи

- Свежий RouterOS export через TimeWeb завершился timeout. Прочитан сохраненный `stage9-bth/router.after.rsc`, а не текущая конфигурация роутера. При следующей правке роутера live audit обязателен.
- Для девяти новых AWG31 устройств нужно подтверждение импорта и работы. MacBook Sergey/iPhone Sergey уже подтверждены пользователем.
- Полная REALITY DNS/IPv6/fail-closed/restart/reboot/recreate и длительная эксплуатационная матрица не закрыта; пользователь откладывал тесты. Документация этого не скрывает.
- Старый WG не имеет доказанной автоматической синхронизации всех server configs в единый локальный deploy-master. Есть рабочий сервер, локальные экспорты и датированные backups; улучшение процесса не реализовано этим ревью.
- До следующего live change обновить backup payload под нынешние контейнеры/каталоги и проверить полноту восстановления. До этого старый run_backup.py не использовать как универсальный актуальный backup.
- Если удаленные из setup-примеров пароли действительно применялись, согласовать их ротацию. Удаление строк из документа не отзывает пароль и не очищает историю Dropbox/backup.
- Удаленный AWG2 нельзя вернуть выбором прежнего профиля. Полный restore из retirement-backup требует отдельной проверки.
- SQL history sync и monitoring pilot нельзя включать как побочный эффект обновления документов. Текущий статус и ограничения описаны отдельно.
- Причина прежних периодических таймаутов/UL 0.00 и инцидентов Cenuta не доказана одной успешной последующей проверкой; утверждения о виновном операторе или точном виде блокировки не добавлены.
