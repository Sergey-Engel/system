## Контроль И Откат

Обновления только после анализа кандидатов, без release upgrade и замены
Docker images. Сохраняются SSH trust и идентичности контейнера/ключей.
До reboot проверить bindings recovery и наличие независимого пути восстановления.
При неготовом recovery исправлять только доказанную причину; не публиковать
неизвестное состояние ради зелёного статуса.

После reboot проверить старые каналы и два новых валидных monitor cycles.
Новый SSTP не получает LAN/default/user routes. При неуспешной приёмке
отключить только новый transport и сохранить диагностику. Настройку IP
выполнять отдельно от существующего DHCP/default route, с проверкой rollback.
Fresh verified backups, hashes и доказательства сохраняются приватно;
публичный журнал содержит только обезличенный состав и результаты.
