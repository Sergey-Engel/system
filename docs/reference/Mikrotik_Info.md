## WinBox
**WinBox** — это фирменная утилита от MikroTik для графической настройки и управления RouterOS. 

### Ключевые особенности:
1. **Подключение по MAC-адресу**: Позволяет настроить роутер, даже если у него нет IP-адреса. Поиск идет через вкладку `Neighbors`.
2. **Real-time интерфейс**: Все данные (трафик, сессии) обновляются мгновенно без перезагрузки страниц.
3. **Безопасность**: Использует зашифрованный протокол на порту TCP `8291`.
4. **Портативность**: Один исполняемый файл `.exe`, не требующий установки.

### Где скачать:
Всегда скачивайте WinBox только с официального раздела [mikrotik.com/download](https://mikrotik.com/download).

> [!tip] Версии
> - **WinBox 3.x**: Классическая версия для Windows.
> - **WinBox 4 (Beta)**: Новое поколение с нативной поддержкой macOS и Linux.
